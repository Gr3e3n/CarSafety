# 提示词工程阶梯实验报告

## 一、实验设计

- **P 系列固定输入**：各组均使用相同全量结构化事故数据（事件/责任/环境/决策链/遥测/派生信号）。
- **累积阶梯**：Baseline → P1(Role) → P2(Structured) → P3(CoT) → P4(Few-shot) → P5(可信约束) → P6(增量语义)。
- **C_D0**：当前项目生产 Prompt（结构化全量输入 + 完整输出规范），与 P 系列同表对比。
- **A/B/C**：系统方法对比（输入信息量可不同）。

主评价指标为 **PQI（生产质量指数）**；表中同时列出裸证据召回 Re 与校准证据召回 Re*（惩罚证据条数超出金标准）。裸 Re 偏高常见于 Baseline 等无输出约束的 Prompt（多写易撞词），不代表生产质量更优。
