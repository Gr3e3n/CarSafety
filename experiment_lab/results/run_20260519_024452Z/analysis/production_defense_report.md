# 生产方案答辩指标报告（推荐主引用）

## 一、为什么用 PQI 而不是裸 Re

生产上线要求：**证据召回 + 结构化合规 + 九字段齐全 + 证据条数不过量**。
单纯 Re 会奖励「多写证据、堆砌关键词」；**PQI（生产质量指数）** 在 Re 基础上加入结构分，
并对证据条数超过金标准（>1.0）的组别扣分，更贴近可部署质量。

**PQI 权重**：Re 28% + 证据校准 12% + 可读 15% + 结构化 22% + 字段齐全 18% + 置信度 5%
