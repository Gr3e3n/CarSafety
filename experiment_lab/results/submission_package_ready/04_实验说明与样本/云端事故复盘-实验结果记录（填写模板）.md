**指标说明（与《云端事故复盘能力实验说明文档》§7 一致）：**

- **\(R_e\)**：该样本该方法下 \(N_{\mathrm{hit}}/N_{\mathrm{gold}}\)（\(N_{\mathrm{gold}}\) 见上表）。
- **责任一致**：生成结果主要责任因素与金标准是否一致（填「是」/「否」）。
- **\(N_{\mathrm{wrong}}\)**：与输入不符的事实陈述条数（团队需事先约定计数规则）。
- **\(N_{\mathrm{claim}}\)**：模型输出中被计为「可核查事实陈述」的总条数（同上）。
- **\(E_f\)**：本行可填比值 \(N_{\mathrm{wrong}}/N_{\mathrm{claim}}\)；若 \(N_{\mathrm{claim}}=0\) 填「—」并备注。
- **可读性**：建议 1～5 分，或四维（清晰/结构/友好/追责）平均分，在表下「计分约定」写明。

### 3.1 计分约定（团队内部统一后填写）

1. **\(R_e\)、责任一致**：跑批得到各方法输出后，与 §2.2 金标准对照手算或脚本统计；`responsibility.reasons` 条数已记为 \(N_{\mathrm{gold}}\)。
2. **\(N_{\mathrm{wrong}}\)、\(N_{\mathrm{claim}}\)、\(E_f\)**：团队事先约定「可核查事实陈述」拆分规则后，对模型输出逐条计数。
3. **可读性**：单人实验建议 1～5 分（或四维均分），保留打分依据（截图/批注）备查。
4. **工具**：批量 JSON 可经 `VehTrust0518/backend/export_batch_results_to_csv.py` 导出后再回填本表。

E_f = \frac{N_{\mathrm{wrong}}}{N_{\mathrm{claim}}}
