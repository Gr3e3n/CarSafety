# 模拟 500 条 → 500 次独立请求调 AI → 导出

与 App 一致：每条事故 **一个 JSON**，对应 **一次** `POST /api/accident/analyze`（不是把 500 条塞进 `/analyze/batch` 一次提交）。  
脚本会 **并发** 发 500 个请求，终端显示 **进度条**（`tqdm`）。

---

## 终端 A：启动后端（保持运行）

```powershell

pip install -r requirements.txt
python -m uvicorn main:app --host 0.0.0.0 --port 8080 --reload
```

检查：


`openai_configured` 须为 `true`（`backend\.env` 配置 `OPENAI_API_KEY`，见 `OPENAI使用说明.md`）。

## 终端 B-1：模拟 500 条事故

```powershell
cd D:\Users\Desktop\sax_0522_1\backend
python generate_experiment_samples.py --count 500 --output experiment_samples_500.json
```

勿复制到 `app/src/main/assets/`。

## 终端 B-2：500 个独立请求 + 进度条

```powershell
cd D:\Users\Desktop\sax_0522_1
pip install tqdm httpx
python experiment_lab/run_prompt_experiment.py ^
  --samples backend/experiment_samples_500.json ^
  --groups C ^
  --ablation D0 ^
  --mode http ^
  --base-url http://127.0.0.1:8080 ^
  --http-timeout 900 ^
  --workers 4 ^
  --out-dir blockchain_test_export/output/run_500_new ^
  --skip-analysis
```

说明：

| 项 | 含义 |
|----|------|
| 默认（不加 `--batch-endpoint`） | **500 次** `POST /api/accident/analyze`，每次 body 为一条事故 |
| `--workers 4` | 同时 4 个请求在飞（与后端 `batch_concurrency` 概念类似）；`0` 则读 `/health` 自动取值 |
| 进度条 | `C_D0: 45%|████…| 230/500 [ok=228 fail=2]` |
| `--skip-analysis` | 只保留模型 JSON，不跑实验统计 |

若要用 **一次 HTTP** 提交 500 条（`/analyze/batch`，无逐条进度），显式加：

```powershell
--batch-endpoint
```

先试 5 条：

```powershell
python generate_experiment_samples.py --count 5 --output experiment_samples_5.json
python experiment_lab/run_prompt_experiment.py --samples backend/experiment_samples_5.json --groups C --ablation D0 --mode http --workers 2 --skip-analysis --out-dir blockchain_test_export/output/test_5
```

## 终端 B-3：严重度 + 合并为单一上链包

与 App `CollisionSeverityApi` 一致：读取 `app/src/main/assets/collision_severity_model.json`，对每条遥测做**端侧离线**严重度推断，再与样本、AI 结果按 `eventId` 合并。

```powershell
cd D:\Users\Desktop\sax_0522_1
python blockchain_test_export/merge_run500_for_blockchain.py ^
  --samples backend/experiment_samples_500.json ^
  --results blockchain_test_export/output/run_500_new/cloud_experiment_results_C_D0_20260522_190247Z.json ^
  --out-dir blockchain_test_export/output/run_500_new ^
  --device-id veh-trust-lab-500
```

（`--results` 换成你实际生成的 `cloud_experiment_results_*.json` 文件名。）

| 输出文件 | 用途 |
|----------|------|
| `blockchain_full_records_500_<UTC>.json` | **一份总文件**：`records`（原始+责任+严重度+AI）+ `blockchainUploads` |
| `blockchain_upload_500_<UTC>.json` | 上链数组：`[{deviceId, data}, …]`，字段均为字符串 |
| `blockchain_upload_500_<UTC>.jsonl` | 同上，**一行一条**，便于脚本逐条 `invoke` |

上链 `data` 为业务可读字段：严重度 `predictedSeverity` / `severityScore` / `severitySummary` / `severityHighlights`，AI 复盘正文（不含 `modelHint`、实验组、Token 等内部信息）。
