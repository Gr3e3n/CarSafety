## 1. 概述

### 1.1 项目背景

VehTrust 是一款基于端侧智能分析与区块链可信存证的车载事故智证平台。该平台采用 20Hz 高频采样的方式监控车辆运行状态，在发生碰撞事故时自动采集、分析和存证事故数据。

### 1.2 测试目的

本测试旨在验证 VehTrust 应用在 Android 平台上的各项功能是否按设计要求正常运行，包括：

- ✓ 事故监控与采集功能的正确性
- ✓ 数据展示与交互的流畅性
- ✓ 离线分析（严重度推理）的可靠性
- ✓ 在线分析（AI 研判）的准确性及降级机制
- ✓ 区块链存证的完整性

### 1.3 测试范围

| 模块 | 版本 | 状态 |
|------|------|------|
| 标准版 App | v1.0 | ✓ 测试中 |
| 车机大屏版 | v1.0 | ◐ 可选 |
| 后端 AI 服务 | FastAPI | ◐ 可选 |
| 区块链网关 | Go | ◐ 可选 |

### 3.2 数据采集与处理流程

```
传感器数据 (50ms 采样)
    ↓
[环形缓冲 - 25秒窗口]
    ↓
[触发检测] → 加速度 ≤ -3.0 m/s²
    ↓ (是)
[冻结前 10s + 继续后 10s] → 20 秒事故窗口
    ↓
[责任分析] → 反应时间、制动特性、TTC
    ↓
[离线推理] → CollisionSeverityApi (三分类、概率)
    ↓
[AI 分析] → OpenAI API (结构化研判)
    ↓
[区块链存证] → BlockchainAPI (Hash + 时间戳)
    ↓
[Room 持久化] → 数据库 + UI 展示
```

#### 4.3.5 本地严重度推理（离线）

**功能说明**：

调用 `CollisionSeverityApi` 加载 `collision_severity_model.json` 进行离线推理，输出三分类预测结果。

**场景**：断网或快速推理（不依赖网络）

**步骤**：

1. 关闭网络（WiFi 和蜂窝）
2. 滚动到"深度学习分析"区
3. 点击"生成本地严重度研判"按钮
4. 等待加载完成（通常 < 3 秒）
5. 观察返回的结果

**预期结果**：

✓ < 3 秒内返回结果  
✓ 不依赖网络连接  
✓ 显示以下字段：
