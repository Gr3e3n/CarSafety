# VehTrust 模拟器测试操作指南

**适用环境**：Android Studio 内置模拟器  
**最后更新**：2026-05-23

---

## 1. 环境准备

### 1.1 确认模拟器状态

1. 打开 Android Studio
2. 点击工具栏 **Device Manager** 图标（或 Tools → Device Manager）
3. 确认已创建一台模拟器，推荐配置：
   - **设备型号**：Pixel 6 或 Pixel 6 Pro
   - **系统镜像**：Android 11+（API 30+），选择 `x86_64` 镜像
   - **RAM**：≥ 4GB
   - **存储**：≥ 2GB
4. 点击模拟器右侧的 ▶ 启动按钮，等待模拟器完全启动（看到桌面）

### 1.2 确认 adb 连接

```bash
# 查看已连接的设备
adb devices
```

输出应包含 `emulator-5554  device`，表示模拟器已连接。

### 1.3 启动后端服务（如需测试 AI 分析和区块链）

```bash
# 终端 1：启动 AI 分析后端
cd backend
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python -m uvicorn main:app --host 0.0.0.0 --port 8080
```

保持终端运行，看到 `Uvicorn running on http://0.0.0.0:8080` 表示启动成功。

验证：

```bash
curl http://127.0.0.1:8080/health
```

### 1.4 构建并安装 APK

```bash
# 在项目根目录执行
.\gradlew.bat :app:assembleDebug

# 安装到模拟器
adb install -r app\build\outputs\apk\debug\app-debug.apk
```

看到 `Success` 即安装完成。模拟器桌面出现 VehTrust 应用图标。

## 2. 截图方法

测试过程中需要截图保存到 `Test/pic/` 目录，按编号命名（1.png, 2.png, ...）。

### 方式一：模拟器自带截图

模拟器右侧工具栏点击 📷 相机图标 → 保存 → 手动改名放入 `Test/pic/`。

### 方式二：adb 命令（推荐）

```bash
# 截图
adb shell screencap /sdcard/screen.png

# 拉取到本地（按编号替换 N）
adb pull /sdcard/screen.png Test/pic/N.png
```

**建议**：测试过程中保持 Android Studio 的 **Logcat** 面板打开（底部工具栏），过滤 `vehtrust` 关键字，方便观察日志和排查问题。

## 3. 功能测试操作步骤

以下步骤按照测试文档章节顺序编排。每步操作后，记录实际结果并截取对应编号的截图。

---

### 步骤 1：主页与通知栏（对应 F1、F2）

| 截图 | 1.png、2.png |
|------|-------------|

1. 在模拟器中点击 VehTrust 图标启动应用
2. 观察主页加载：顶部时间实时跳动、6 个模块卡片 + "事故溯源"大卡片完整展示（**截 1.png**）
3. 下拉通知栏：确认存在 VehTrust 前台服务通知，文案含"事故溯源监控中""20Hz""事故前后 10 秒"（**截 2.png**）
4. 点击任意一个模块卡片（如"驾驶行为"）→ 跳转至模块详情页 → 返回
5. 点击"事故溯源"大卡片 → 跳转至事故列表页

**检查点**：通知栏通知不消失（前台服务常驻）、模块卡片点击响应正常、页面跳转无白屏。

---

### 步骤 2：事故列表与云实验设置（对应 F3、F12）

| 截图 | 3.png、4.png |
|------|-------------|

1. 在事故溯源列表页观察列表内容：至少 1 条记录，每条含 ID、时间、地点、原因（**截 3.png**）
2. 点击底部"云实验设置"按钮 → 进入实验设置页
3. 依次点击方案 C 和模式 D0，观察选中状态切换（**截 4.png**）
4. 按 Back 返回列表，再重新进入实验设置页 → 确认配置保持（持久化验证）

**检查点**：列表无白屏、条目信息完整、实验配置选择后点击生效、重启应用后配置保留。

---

### 步骤 3：事故详情 — 基本信息与责任指标（对应 F3、F4）

| 截图 | 5.png、6.png |
|------|-------------|

1. 在事故列表页点击第一条事故记录
2. 进入详情页后滚动到顶部，确认事件基本信息卡片完整展示：ID、类型、时间、位置、原因（**截 5.png**）
3. 向下滚动到"责任分析"区域，观察三个指标卡片：反应时间（橙色）、制动响应（蓝色）、峰值减速度（紫色）—— 数值有效，无 NaN（**截 6.png**）

**检查点**：详情页 < 1 秒加载、信息卡片字段无缺失、指标数值为合理的非空数字。

---

### 步骤 4：遥测回放（对应 F5）

| 截图 | 7.png |
|------|------|

1. 滚动到"遥测回放"区域
2. 将 SeekBar 拖动到中间位置（碰撞时刻附近），观察右侧数据是否实时更新
3. 点击 **播放** 按钮，观察 SeekBar 自动匀速推进，遥测曲线同步变化
4. 点击 **暂停** 停止播放
5. 点击 **重新开始** 回到起始位置（碰撞前 10 秒）
6. 找一个数据更新明显的时刻（如速度骤降点），截取回放状态图（**截 7.png**）

**检查点**：SeekBar 拖动时数据实时更新、播放过程不卡顿、播放/暂停/重新开始按钮逻辑正确。

---

### 步骤 5：碰撞严重度预测（对应 F6）

| 截图 | 8.png |
|------|------|

1. 在模拟器中关闭 Wi-Fi（从顶部下拉菜单关闭，或使用命令 `adb shell svc wifi disable`）
2. 滚动到"碰撞严重度预测"区域
3. 点击 **生成碰撞严重度预测** 按钮
4. 等待 < 3 秒，观察结果展示（**截 8.png**）

**检查点**：离线可正常返回结果、显示预测分类/置信度/严重度指数/概率分布/关键因素。

---

### 步骤 6：AI 结构化分析 — 在线模式（对应 F7）

| 截图 | 9.png |
|------|------|

1. 恢复网络连接（`adb shell svc wifi enable`，或从模拟器下拉菜单开启 Wi-Fi）
2. 确认后端服务正在运行（`curl http://127.0.0.1:8080/health`）
3. 滚动到"AI 事故分析"区域
4. 点击 **发起 AI 事故分析** 按钮
5. 等待返回结果（通常 5~30 秒），观察结构化字段展示（**截 9.png**）

**检查点**：返回字段完整（摘要/责任/分析/证据/建议/模型）、无 JSON 解析错误、文本可读。

---

### 步骤 7：AI 分析 — 离线降级（对应 F8）

| 截图 | 10.png |

1. 关闭后端服务（在终端按 `Ctrl+C`）
2. 返回详情页，再次点击 **发起 AI 事故分析**
3. 观察降级提示和本地分析结果展示（**截 10.png**）

**检查点**：显示明确的离线降级提示、返回本地模板化分析内容、无崩溃无白屏。

### 步骤 8：地图与区块链存证（对应 F9、F10、F11）

| 截图 | 11.png、12.png、13.png |
|------|----------------------|

**地图测试：**

## 5. 快捷操作速查

```bash
# 重启 adb（连不上模拟器时）
adb kill-server && adb start-server

# 模拟器 Wi-Fi 开关
adb shell svc wifi disable    # 关
adb shell svc wifi enable     # 开

# 模拟网络延迟（模拟弱网）
adb shell settings put global network_latency 2000   # 2 秒延迟
adb shell settings delete global network_latency     # 恢复

# 查看应用进程
adb shell ps | grep vehtrust

# 强制停止应用
adb shell am force-stop com.example.vehtrust

# 清空应用数据（重置使用痕迹）
adb shell pm clear com.example.vehtrust

# 卸载重装
adb uninstall com.example.vehtrust
.\gradlew.bat :app:installDebug

# 查看 Android 版本
adb shell getprop ro.build.version.release

# 查看当前 Activity
adb shell dumpsys activity activities | grep mResumedActivity
```
